# 🚀 Deployment Guide: Railway (Recommended - Easiest)

Railway is the easiest and offers $5 free credit monthly.

### Step 1: Prepare Your Code

Create `.gitignore`:
```
venv/
__pycache__/
*.pyc
.env
instance/
*.db
.DS_Store
```

### Step 2: Initialize Git

```bash
git init
git add .
git commit -m "Initial commit"
```

### Step 3: Push to GitHub

```bash
# Create a new repository on GitHub first, then:
git remote add origin https://github.com/yourusername/cultivator-era.git
git branch -M main
git push -u origin main
```

### Step 4: Deploy on Railway

1. Go to [railway.app](https://railway.app)
2. Click **"Start a New Project"**
3. Select **"Deploy from GitHub repo"**
4. Choose your `cultivator-era` repository
5. Railway will auto-detect Flask and deploy

### Step 5: Add Database

1. In your project dashboard, click **"New"** → **"Database"** → **"PostgreSQL"**
2. Railway automatically sets `DATABASE_URL` environment variable

### Step 6: Set Environment Variables

In Railway dashboard, go to **Variables** tab:

```
SECRET_KEY=your-super-secret-key-change-this-in-production
ADMIN_EMAIL=admin@yourdomain.com
FLASK_ENV=production
```

### Step 7: Initialize Database

In Railway dashboard:
1. Go to **Settings** → **Deploy**
2. Under **Custom Start Command**, add:
```
python init_db.py && gunicorn --worker-class eventlet -w 1 app:app
```

Or run manually:
1. Go to project → **Settings** → **Terminal**
2. Run: `python init_db.py`

### Step 8: Access Your App

Railway provides a URL like: `https://cultivator-era-production.up.railway.app`

**Cost**: $5/month free credit (enough for small traffic)

# 🚀 Deployment Guide: Heroku

### Step 1: Install Heroku CLI

**Windows:**
Download from [devcenter.heroku.com/articles/heroku-cli](https://devcenter.heroku.com/articles/heroku-cli)

**Mac:**
```bash
brew tap heroku/brew && brew install heroku
```

**Linux:**
```bash
curl https://cli-assets.heroku.com/install.sh | sh
```

### Step 2: Login to Heroku

```bash
heroku login
```

### Step 3: Create Heroku App

```bash
heroku create cultivator-era-game
# Or let Heroku generate a name:
# heroku create
```

### Step 4: Add PostgreSQL Database

```bash
heroku addons:create heroku-postgresql:mini
```

### Step 5: Set Environment Variables

```bash
heroku config:set SECRET_KEY=$(python -c 'import secrets; print(secrets.token_hex(32))')
heroku config:set FLASK_ENV=production
heroku config:set ADMIN_EMAIL=admin@yourdomain.com
```

### Step 6: Deploy

```bash
git add .
git commit -m "Ready for deployment"
git push heroku main
```

### Step 7: Initialize Database

```bash
heroku run python init_db.py
```

### Step 8: Open Your App

```bash
heroku open
```

### Step 9: View Logs (if issues)

```bash
heroku logs --tail
```

**Cost**: Heroku removed free tier. Starts at $7/month for Eco Dynos.

# 🚀 Deployment Guide: DigitalOcean App Platform

### Step 1: Prepare Repository

Ensure your code is on GitHub (same as Railway steps 1-3 above).

### Step 2: Create DigitalOcean Account

1. Go to [digitalocean.com](https://digitalocean.com)
2. Sign up (get $200 free credit for 60 days with credit card)

### Step 3: Create New App

1. Go to **Apps** in sidebar
2. Click **"Create App"**
3. Choose **"GitHub"** as source
4. Select your repository
5. Select branch: `main`

### Step 4: Configure Build Settings

DigitalOcean auto-detects Python. Verify:

- **Build Command**: `pip install -r requirements.txt`
- **Run Command**: `gunicorn --worker-class eventlet -w 1 app:app`

### Step 5: Add Database

1. Click **"Add Resource"** → **"Database"**
2. Choose **PostgreSQL**
3. Select **"Dev Database"** ($7/month) or **"Basic"** ($15/month)
4. DigitalOcean auto-sets `DATABASE_URL`

### Step 6: Set Environment Variables

In **App Settings** → **App-Level Environment Variables**:

```
SECRET_KEY=your-super-secret-key-here
FLASK_ENV=production
ADMIN_EMAIL=admin@yourdomain.com
```

### Step 7: Deploy

1. Click **"Next"** through remaining steps
2. Review and click **"Create Resources"**
3. Wait 5-10 minutes for deployment

### Step 8: Initialize Database

1. Go to **Console** tab in your app
2. Click **"Launch Console"**
3. Run: `python init_db.py`

### Step 9: Custom Domain (Optional)

1. Go to **Settings** → **Domains**
2. Add your domain
3. Point DNS to DigitalOcean nameservers

**Cost**: $5/month (app) + $7/month (database) = $12/month

# 🔧 Post-Deployment Checklist

After deploying to any platform:

### 1. Test Critical Functions

```bash
# Test registration
curl -X POST https://your-app.com/register \
  -d "username=testuser&email=test@email.com&password=test123"

# Test login
curl -X POST https://your-app.com/login \
  -d "username=testuser&password=test123"
```

### 2. Change Admin Password

1. Login as admin
2. Go to your user profile
3. Change password from `admin123` to something secure

### 3. Enable HTTPS

All platforms provide automatic SSL. Verify:
- Your app URL starts with `https://`

### 4. Set Up Monitoring

**For Railway/Heroku:**
- Use built-in metrics dashboard

**For DigitalOcean:**
- Go to **Insights** tab to view metrics

**External Option:**
- Sign up for [UptimeRobot](https://uptimerobot.com) (free)

```bash
heroku pg:backups:schedule --at '02:00 America/Los_Angeles'
```

**DigitalOcean:**
- Automatic daily backups included with managed databases

# 🐛 Troubleshooting Common Issues

### Application Error / 500

**Check logs:**
```bash
# Railway: Use web dashboard logs
# Heroku: heroku logs --tail
# DigitalOcean: Check Runtime Logs tab
```

**Common fix:**
```python
# In app.py, add error handling:
@app.errorhandler(500)
def internal_error(error):
    db.session.rollback()
    return "Internal error", 500
```

### Database Connection Failed

**Verify DATABASE_URL:**
```bash
# Heroku
heroku config

# Railway/DigitalOcean: Check variables in dashboard
```

**Fix Heroku postgres:// issue:**
Already handled in `config.py`:
```python
if SQLALCHEMY_DATABASE_URI.startswith('postgres://'):
    SQLALCHEMY_DATABASE_URI = SQLALCHEMY_DATABASE_URI.replace('postgres://', 'postgresql://', 1)
```

### SocketIO Not Working

**Ensure eventlet is installed:**
```bash
pip install eventlet
```

**Procfile uses eventlet worker:**
```
web: gunicorn --worker-class eventlet -w 1 app:app
```
